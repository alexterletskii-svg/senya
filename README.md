# Сеня — цифровой напарник

Маленький парящий робот живёт в углу рабочего стола поверх всех окон. Напоминает про перерывы, глаза, воду и осанку, ведёт Pomodoro, помнит дела, считает статистику и общается звуками в духе «космических дроидов» (оригинальные синтезированные чирики, без речи).

Целевая платформа — **Windows** (Linux/macOS запускаются, но автоматическое «не беспокоить» работает только на Windows).

## Запуск

```bash
npm install
npm start        # запуск
npm test         # юнит-тесты
npm run dist     # сборка установщика (electron-builder)
```

Нужен Node.js 18+. Окно Сени появляется в правом нижнем углу, иконка — в трее. Горячая клавиша **Ctrl+Alt+S** показывает Сеню и открывает меню.

## Возможности

| Что | Как работает |
|---|---|
| Перерывы | Каждые 25–45 мин: «Размялся ✔» или «+5 мин». Пропустил 3 — Сеня грустит |
| Разминка | 9 микроупражнений (шея, плечи, кисти, потягушки, дыхание, ладони на глаза, наклоны, ходьба) с анимацией и таймером. Выполнение засчитывается как перерыв |
| Глаза | Упражнение 20 секунд на дальнюю точку |
| Вода, осанка | Периодические напоминания |
| Pomodoro | 25 / 5 мин, длинный перерыв 15 мин после 4-го цикла. Сеня в каске |
| Дела | Русский язык: «через 20 минут позвонить», «в 15:30 созвон», «завтра в 9 отчёт» |
| Повторяющиеся дела | «каждый день в 9 зарядка», «по будням в 10:00 планёрка», «каждый понедельник отчёт», «каждые 2 часа вода» |
| Статистика | Сегодня: перерывы, помидоры, дела, разминки, активные минуты. График за неделю |
| Цель и серия | Дневная цель (по умолчанию 6 перерывов/помидоров/разминок); серия дней подряд. Достиг цели — Сеня радуется сердечками |
| Приветствие | При запуске: сколько дел в списке и текущая серия |
| Не беспокоить | Вручную (меню или трей: 1 ч / до завтра / выкл) и автоматически на Windows — см. ниже |
| Звук | Чирики под эмоции и реплики. Громкость и выключение в настройках |
| Спросить Сеню | Чат с DeepSeek (опционально) |

## Эмоции

Бодрый, сосредоточенный, грустный, радостный, влюблённый (сердечки), спящий. Вся эмоция — в форме глаз; лица нет. Глаза следят за курсором.

## Общение

- **Погладить** — водить курсором туда-сюда по Сене (или кнопка «Погладить»): появляются сердечки.
- **Клик** — тык и меню; клик по спящему будит.
- **Перетащить** — Сеня удивляется, при отпускании подпрыгивает.
- **Правый клик** — болтовня.

## Не беспокоить на Windows

Фоновый PowerShell раз в 5 секунд проверяет:

- полноэкранное приложение или презентацию (`SHQueryUserNotificationState`) — Сеня прячется и молчит;
- активный микрофон (звонок) — Сеня молчит, но остаётся на экране.

Отключается настройкой «Авто-тишина». Эта проверка не тестировалась на живой Windows при разработке (только логика разбора и решения юнит-тестами) — если что-то не срабатывает, пишите.

## Чат с DeepSeek

Ключ только через переменную окружения:

```powershell
setx DEEPSEEK_API_KEY "ваш_ключ"
```

Перезапустите Сеню. Необязательно: `DEEPSEEK_BASE_URL` (по умолчанию `https://api.deepseek.com`), `DEEPSEEK_MODEL` (по умолчанию `deepseek-chat`). Без ключа поле чата подсказывает, что ИИ не подключён. Наружу уходят только ваш вопрос и краткая сводка состояния (счётчики, без названий задач).

### Ключ внутри сборки

При `npm run dist:win` скрипт `scripts/embed-key.js` кладёт ключ из `DEEPSEEK_API_KEY` в `src/main/embedded.json` (файл в `.gitignore`, в репозиторий не попадает). В GitHub Actions ключ берётся из секрета репозитория `DEEPSEEK_API_KEY`. Переменная окружения на компьютере главнее встроенного ключа.

## Настройки

В меню: интервалы перерывов, глаза/вода/осанка, дневная цель, громкость и звук, авто-тишина, автозапуск.

## Устройство

- `src/core` — чистая логика (движок с внедряемыми часами, парсер задач, упражнения, фразы), покрыта тестами.
- `src/main` — Electron: окно, трей, хоткей, focusGuard (Windows), ИИ-клиент.
- `src/renderer` — SVG-робот, анимации, звук, интерфейс.

Окно подгоняется под содержимое, поэтому пустая прозрачная область не перехватывает клики. Данные хранятся в `userData/senya.json` (сохранения старого «Робика» не переносятся).

## Не сделано

Интеграция с календарём, озвучка речью и голосовой ввод (по решению автора не нужны).
