# Робик — цифровой напарник

Маленький парящий робот живёт в углу рабочего стола поверх всех окон. Следит за режимом работы, напоминает о перерывах, воде, осанке, гоняет Pomodoro и помнит список дел. Настроение Робика зависит от того, как ты работаешь.

## Запуск

```bash
npm install
npm start
```

Нужен Node.js 18+. Окно Робика появится в правом нижнем углу, иконка — в трее (клик по ней прячет/показывает Робика, в скрытом режиме напоминания не появляются).

- **Клик по роботу** — открыть меню (Pomodoro, дела, настройки). `Esc` закрывает.
- **Перетащить робота** — переместить; позиция запоминается.

## Что умеет

| Функция | Как работает |
|---|---|
| Перерывы | Каждые 30 мин активной работы: «Пора размяться!». Кнопки «Размялся ✓» и «+5 мин» |
| Гимнастика для глаз | Каждые 20 мин предлагает; по кнопке 20 секунд двигается точка (восьмёрка), за ней следим глазами |
| Вода и осанка | Каждые 45 / 35 мин, фразы выбираются случайно и не повторяются подряд |
| Pomodoro | 25 / 5 мин, после 4-го цикла — длинный перерыв 15 мин. В работе Робик в каске и «печатает». Во время таймера остальные напоминания не мешают |
| Список дел | Задача со временем на русском: «через 20 минут позвонить», «в 15:30 созвон», «завтра в 9 утра отчёт». В срок Робик напомнит (Готово / +10 мин) |

Все интервалы и переключатели — в меню → «Настройки».

## Эмоции

Робик — парящий экран с фиолетовым корпусом. Лица как такового нет: вся эмоция в форме глаз.

| Состояние | Когда | Вид |
|---|---|---|
| Бодрый | по умолчанию, после пробуждения | янтарные глаза, моргает, иногда подмигивает и осматривается |
| Сосредоточенный | рабочая фаза Pomodoro | узкие глаза-щёлки, бегущая линия по экрану, каска |
| Грустный | пропущено 3 перерыва подряд | глаза с опущенными углами, слеза, антенна и «плавники» поникли |
| Радостный | задача выполнена | глаза-дуги, подпрыгивает, искры |
| Любовь | погладили; перерыв после грусти | глаза-сердечки, всплывают сердечки |
| Спящий | нет ввода 3 мин | закрытые глаза, «Zzz» |

Простой от 5 минут (или сон компьютера) засчитывается как настоящий перерыв: грусть снимается, таймеры сбрасываются.

## Общение с Робиком

- **Глаза следят за курсором** по всему экрану. Если мышь не двигается, Робик сам осматривается и подмигивает.
- **Погладить** — водить мышкой туда-сюда над ним: появятся сердечки (то же — кнопка «Погладить» в меню). Гладить можно и спящего.
- **Поднять** — зажать и перетащить: Робик удивляется и болтает «плавниками», при отпускании подпрыгивает.
- **Поболтать** — правая кнопка мыши (или кнопка в меню): совет или шутка в облачке.
- **Клик** — меню; клик по спящему Робику будит его.

## Устройство

```
src/core/        логика без Electron: engine.js (состояния, таймеры), taskParser.js, phrases.js
src/main/        Electron: прозрачное окно always-on-top, трей, сохранение, простой системы
src/renderer/    интерфейс: robot.js (SVG), style.css (анимации), app.js
scripts/         screenshots.js (рендер состояний в PNG), make-icon.py (иконка трея)
test/            node:test — движок и парсер задач
```

Окно подгоняется под содержимое (робот, облачко, меню), поэтому пустая прозрачная область не перехватывает клики. Данные хранятся в `userData/robik.json`.

## Разработка

```bash
npm test                      # юнит-тесты (без Electron)
SHOTS_DIR=shots xvfb-run -a npx electron --no-sandbox scripts/screenshots.js   # PNG всех состояний
npm run dist                  # сборка установщика (electron-builder)
```

## Известные ограничения

- Голосового ввода задач пока нет — задачи вводятся текстом.
- Linux: прозрачность требует композитора; на Wayland «поверх всех окон» зависит от окружения.
- На macOS/Windows поверх полноэкранных приложений окно держится уровнем `screen-saver`; проверено только на Linux (xvfb).
